# Censr

> **Source Available • Privacy-First • Real-Time AI Content Filtering**

Censr is a **source-available**, privacy-first browser extension that
performs real-time AI-powered filtering of **images, GIFs, videos, and
livestreams** directly inside your browser.

Unlike cloud-based filters, **everything runs locally on your
computer**. No accounts. No telemetry. No servers. No data collection.

## Highlights

-   🚀 Real-time filtering for images, GIFs, videos, and livestreams
-   🔒 100% client-side (offline capable)
-   🧠 YOLO-based per-body-part detection
-   🎛️ Blur, Pixelate, Black Bar, labels, overlays
-   ⚡ Lightweight and configurable
-   ❤️ Free for personal use

## Privacy

-   No sign-in
-   No logging
-   No analytics
-   No telemetry
-   No cloud processing
-   Your browsing data never leaves your device.

## Installation

1.  Download or clone this repository.
2.  Open `chrome://extensions`
3.  Enable **Developer Mode**
4.  Click **Load unpacked**
5.  Select the extracted Censr folder.
